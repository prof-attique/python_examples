# Módulo 07: Manipulação de Arquivos e Persistência

Neste módulo você aprende a ler e gravar dados em disco, permitindo que as informações persistam mesmo após o término do programa.

## 🎯 Objetivos de Aprendizagem
- Utilizar o gerenciador de contexto `with open(...)` para abertura e fechamento seguro de arquivos.
- Compreender os modos de abertura: leitura (`r`), escrita (`w`) e anexação (`a`).
- Manipular arquivos de texto puro (`.txt`).
- Serializar e desserializar estruturas Python (listas, dicionários) em arquivos `.json`.

## 📁 Arquivos deste Módulo
- [`iniciante.py`](iniciante.py): Criação, leitura e atualização de um arquivo JSON estruturado.
- [`dados.json`](dados.json): Arquivo de dados de exemplo utilizado em [`iniciante.py`](iniciante.py).
- [`sites.py`](sites.py) e [`sites.txt`](sites.txt): Manipulação de listas de endereços em arquivos texto.
- [`teste.py`](teste.py): Processador de arquivos de diretórios e extração de conteúdo.
