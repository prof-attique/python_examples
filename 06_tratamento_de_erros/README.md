# Módulo 06: Tratamento de Erros e Exceções

Aprenda a construir programas robustos que lidam com situações imprevistas sem quebrar a execução.

## 🎯 Objetivos de Aprendizagem
- Identificar os tipos mais comuns de erros em Python (`ValueError`, `ZeroDivisionError`, `TypeError`, `FileNotFoundError`).
- Tratar exceções com blocos `try` e `except`.
- Executar ações pós-sucesso com o bloco `else`.
- Garantir a liberação de recursos com o bloco `finally`.

## 📁 Arquivos deste Módulo
- [`try_iniciante.py`](try_iniciante.py): Primeiros passos com captura de exceções em tempo de execução.
- [`lista_exercicio.py`](lista_exercicio.py): Exercícios guiados para praticar proteção de fluxo e entradas inválidas.
