# Módulo 02: Estruturas Condicionais

Neste módulo você aprende a controlar o fluxo de execução do programa através de condições booleanas.

## 🎯 Objetivos de Aprendizagem
- Avaliar expressões com operadores relacionais (`==`, `!=`, `>`, `<`, `>=`, `<=`).
- Combinar condições com operadores lógicos (`and`, `or`, `not`).
- Construir desvios condicionais com `if`, `elif` e `else`.
- Utilizar Pattern Matching com `match-case` (recurso moderno do Python 3.10+).

## 📁 Subdiretórios
- [`if_else/`](if_else/): Exemplos práticos como cálculo de imposto de renda, médias ponderadas, testes de paridade e tabela lógica.
- [`match_case/`](match_case/): Exemplos de substituição de múltiplos `if/elif` por casamento de padrões estruturais e cálculo de parcelas.
