# Módulo 09: Tópicos Avançados

Este módulo aprofunda em conceitos além da sintaxe básica, cobrindo assincronismo, padrões de projeto e algoritmos.

## 📁 Subdiretórios
- [`algoritmos/`](algoritmos/): Medições de desempenho (`timeit`), testes com type hints, algoritmo de paginação e jogo Jokenpô.
- [`async/`](async/): Programação concorrente e assíncrona com `async` e `await`.
- [`matematica_discreta/`](matematica_discreta/): Análise combinatória e lógica de relações (reflexivas e ordem parcial).
- [`padroes_de_projeto/`](padroes_de_projeto/): Implementações de Design Patterns GoF:
  - `01_adapter/`: Padrão estrutural Adapter.
  - `05_factory/`: Padrão criacional Factory Method para processamento de pagamentos.
