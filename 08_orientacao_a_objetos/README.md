# Módulo 08: Programação Orientada a Objetos (POO)

Aprenda os pilares do paradigma de orientação a objetos aplicado à sintaxe do Python.

## 🎯 Objetivos de Aprendizagem
- Criar classes com a palavra-chave `class`.
- Inicializar objetos através do método construtor `__init__`.
- Diferenciar variáveis e métodos de classe vs. de instância.
- Sobrescrever métodos especiais como `__str__` para representação textual.
- Modularizar entidades e chamá-las no script principal de execução.

## 📁 Arquivos deste Módulo
- [`modelos.py`](modelos.py): Definição de classes de domínio (`Aluno`, `Produto`, `Carro`).
- [`principal.py`](principal.py): Script de demonstração que instancia os objetos de [`modelos.py`](modelos.py) e executa seus métodos.
- [`pessoa.py`](pessoa.py): Exemplo complementar de modelagem de pessoa e manipulação de atributos.
