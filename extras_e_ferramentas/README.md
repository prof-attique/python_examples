# Extras, Bibliotecas e Ferramentas

Projetos complementares utilizando bibliotecas externas do ecossistema Python e scripts comparativos entre linguagens.

## 📁 Subdiretórios
- [`automacao/`](automacao/): Automação de tarefas com PyAutoGUI e simulação lógica de robô resgatista.
- [`blockchain/`](blockchain/): Implementação conceitual de uma blockchain básica.
- [`comparativo_linguagens/`](comparativo_linguagens/): Códigos equivalentes escritos em C, JavaScript, TypeScript, C# e Java para fins didáticos de comparação de sintaxe e desempenho.
- [`crawler/`](crawler/): Exemplo de web spider utilizando o framework Scrapy.
- [`interfaces_graficas/`](interfaces_graficas/): Exemplos de GUI com Tkinter e Kivy.
- [`processamento_imagens/`](processamento_imagens/): Visualização e manipulação de imagens térmicas com Matplotlib.
- [`web_e_scraping/`](web_e_scraping/): Requisições HTTP e extração de páginas web com `requests`.
