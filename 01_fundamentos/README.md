# Módulo 01: Fundamentos da Linguagem Python

Este módulo aborda os primeiros passos na programação em Python: como interagir com o usuário, armazenar dados em variáveis e realizar operações matemáticas básicas.

## 🎯 Objetivos de Aprendizagem
- Executar scripts Python no terminal.
- Coletar dados do teclado com `input()`.
- Exibir dados formatados com `print()` e f-strings.
- Converter tipos de dados (`int`, `float`, `str`).
- Aplicar operadores aritméticos (`+`, `-`, `*`, `/`, `//`, `%`, `**`).

## 📁 Arquivos deste Módulo
- [`helloworld.py`](helloworld.py): O clássico primeiro programa em qualquer linguagem.

- [`distancia.py`](distancia.py) / [`distancia_calculo.py`](distancia_calculo.py): Leitura de dados, cálculo de velocidade média e tempo de viagem.
- [`area.py`](area.py) / [`area2.py`](area2.py): Cálculo de áreas geométricas.
- [`anos.py`](anos.py) / [`datas.py`](datas.py): Cálculos de idade e operações temporais básicas.
- [`mudavalor.py`](mudavalor.py): Demonstração da mutabilidade de variáveis e atribuições sequenciais.
- [`exercicios_iniciantes.py`](exercicios_iniciantes.py): Lista de exercícios básicos para fixação.
