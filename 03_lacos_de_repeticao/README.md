# Módulo 03: Laços de Repetição

Aprenda a iterar sobre dados e executar blocos de código repetidamente de forma controlada.

## 🎯 Objetivos de Aprendizagem
- Utilizar `while` para laços baseados em condições booleanas e menus iterativos.
- Utilizar `for` para iterar sobre sequências (`range`, listas, strings).
- Controlar a execução com comandos de interrupção: `break` e `continue`.
- Explorar particularidades do Python como o bloco `else` após loops (`for-else` e `while-else`).
- Enumerar elementos com a função `enumerate()`.

## 📁 Subdiretórios
- [`while/`](while/): Validação de credenciais de login, cálculo de médias com notas variáveis, tabuada e simulação de crescimento populacional.
- [`for/`](for/): Gerador de tabelas da verdade, contagem de vogais, busca de maior/menor elemento e iterações com filtros condicionais.
