# Módulo 04: Estruturas de Dados e Coleções

Python oferece coleções nativas extremamente poderosas. Este módulo explora cada uma delas e quando utilizar cada estrutura.

## 🎯 Objetivos de Aprendizagem
- **Strings**: Fatiamento de texto (`[inicio:fim:passo]`), métodos de busca e substituição.
- **Listas**: Sequências mutáveis e ordenadas; métodos `append()`, `pop()`, `remove()`, indexação negativa.
- **Tuplas**: Coleções imutáveis para proteção de dados e empacotamento/desempacotamento.
- **Dicionários**: Coleções baseadas em chave-valor, iteração por `.keys()`, `.values()`, `.items()`, e listas de dicionários.

## 📁 Subdiretórios
- [`01_strings/`](01_strings/): Manipulações e testes com texto.
- [`02_listas/`](02_listas/): Listas de compras, operações de remoção e inserção.
- [`03_tuplas/`](03_tuplas/): Exemplos práticos com registros imutáveis.
- [`04_dicionarios/`](04_dicionarios/): Cadastros de produtos, relatórios de estoque e modelagem de entidades.
